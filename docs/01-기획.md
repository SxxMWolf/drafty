# 기획

## 무엇을 만들려고 했는지

Drafty는 브라우저에서 텍스트를 고치거나 요약하는 도구다.

README와 코드 기준 구성은 세 갈래다.

| 구성 | 경로 | 역할 |
|------|------|------|
| Chrome 확장 | `extension/` | 페이지에서 텍스트 선택 → Enhance(고쳐쓰기) 또는 Extract(요약) |
| Node 백엔드 | `rewrite-server/` | OpenAI로 실제 처리 |
| iOS 커스텀 키보드 | `DraftyKeyboard/` | Beta. Enhance만 지원 |

초기 README(`555d5d0`, 2026-01-26)에서는 버튼 이름이 **Polish / Digest**였다. README·UI 이름이 **Enhance / Extract**로 바뀐 시점은 `7e52f30`(2026-01-27)이다. 고쳐쓰기 + 요약 기능 축은 첫 README·첫 커밋부터 있다.

## 해결하려던 문제 / 동기

초기 README(`555d5d0`, 2026-01-26)에 적힌 제약:

- iOS 키보드에서는 Digest(`7e52f30`, 2026-01-27에 Extract로 개명)를 지원하지 않는다 — UI·데이터 접근 제한, 타이핑 흐름을 깨기 쉽다는 이유

그 외 개인 동기나 타깃 사용자는 README에 명시되어 있지 않다.

`docs/deployment_materials.md` 제목은 “Chrome Web Store Listing for Drafty”이며, “탭을 벗어나지 않고 쓰기·읽기” 문구가 있다.
