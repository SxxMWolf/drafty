# 설계 및 구현 계획

## 사용 기술

| 기술 | 역할 | 코드에서의 사용 |
|------|------|-----------------|
| Chrome Extension Manifest V3 | 확장 셸 | `extension/manifest.json` — content script, popup, service worker |
| Vanilla JS / HTML / CSS | 확장 UI·로직 | `content.js`, `popup.html` / `popup.js`. 프레임워크 없음 |
| Node.js + Express | API 서버 | `rewrite-server/server.js` — `/api/enhance`, `/api/extract` |
| cors | CORS | `origin: true` (코드 주석: `CORS (Allow All Origins)`) |
| express-rate-limit | 요청 제한 | `/api/`에 15분 100회 |
| OpenAI SDK (`openai`) | LLM 호출 | `gpt-4o-mini`, chat completions |
| Render | 배포 | README·코드의 `https://drafty-ssa4.onrender.com` |
| Swift / UIKit | iOS 키보드 | `KeyboardViewController.swift` — Enhance + 톤 메뉴 |
| App Group `UserDefaults` | iOS 톤 저장 | `group.com.drafty.shared` |

README Tech Stack의 모델명 표기와 코드 불일치는 [최종 정리 > 한계 / 임시방편](05-최종-정리.md)의 「모델명 불일치」 항목 참조.

스택을 택한 이유는 README·커밋 메시지에 없다. (확인 필요)

## 아키텍처 / 모듈 구조

```text
[웹페이지] --선택--> content.js (플로팅 버튼 / Extract 카드)
                         |
                         | POST + x-api-key
                         v
              rewrite-server (Express on Render)
                         |
                         v
                      OpenAI API

[툴바 아이콘] --> popup.js --tone--> chrome.storage.sync
                                      ^
                    content.js가 enhance/extract 요청 시 읽음

[iOS 키보드] --> KeyboardViewController --> 동일 /api/enhance
```

| 파일 | 역할 |
|------|------|
| `background.js` | MV3용 service worker. 주석 2줄만 있고 로직 없음 |
| `content.js` | 선택 감지, Enhance/Extract 분기, DOM 치환, Extract 카드 UI |
| `popup.html` / `popup.js` | 톤 5종 저장 |
| `server.js` | 입력 길이 제한(4000자), 출력 clamp, API 키 검사, rate limit |
