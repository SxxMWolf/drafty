# 사용방법

README와 코드를 대조했을 때, 실제 동작은 코드 기준으로 적는다.

## 요구사항

| 환경 | 필요 |
|------|------|
| Chrome 확장 | Chrome(또는 Chromium), Developer mode |
| 로컬 서버 | Node.js, npm |
| iOS 키보드 | Xcode, Apple ID 서명 |
| API | OpenAI API 키 + 서버용 `API_KEY` (로컬/자체 배포 시) |

## Chrome 확장

1. 저장소 clone
2. `chrome://extensions` → Developer mode → Load unpacked
3. `extension` 폴더 선택
4. 기본값으로 프로덕션 서버 `https://drafty-ssa4.onrender.com` 사용

## 로컬 서버

```bash
cd rewrite-server
npm install
```

환경변수 (코드 기준):

```bash
export OPENAI_API_KEY=...   # (실제 값은 별도 비공개 노트 참조)
export API_KEY=...          # 클라이언트 x-api-key와 동일해야 함. (실제 값은 별도 비공개 노트 참조)
export PORT=8080            # 선택, 기본 8080
npm start
```

그다음:

1. `extension/content.js`의 `API_BASE_URL`을 `http://localhost:8080`으로 변경
2. `API_KEY` 상수를 서버 `API_KEY`와 맞춤. `(실제 값은 별도 비공개 노트 참조)`
3. 현재 `manifest.json`의 `host_permissions`는 `https://drafty-ssa4.onrender.com/*`만 포함한다. localhost 호출을 위해 `http://localhost:8080/*`(또는 `http://127.0.0.1:8080/*`) 추가가 필요한지 (미검증 — 이 환경에서 Chrome 확장 content script 로컬 연결 테스트를 완료하지 못함)

## iOS 키보드 (Beta)

1. `DraftyKeyboard/DraftyKeyboard.xcodeproj` 열기
2. 서명 후 시뮬레이터/기기 실행
3. 설정에서 키보드 추가 + Full Access (네트워크용)

## 사용

| 플랫폼 | 방법 |
|--------|------|
| 데스크톱 | 텍스트 선택 → Enhance 또는 Extract. 툴바 아이콘에서 톤 선택 |
| iOS | 키보드에서 Tone 선택 후 Enhance |
